PAL Frame Structure

625 lines per frame, 50 fields/sec, 25 frames/sec.
Field 1: v_cnt 0–311 (scope lines 1–312)
Field 2: v_cnt 312–624 (scope lines 313–625)
F2 starts at v_cnt=312, h_cnt=320 (half-line offset — the key to interlacing).

Pixel Clock

10 MHz pixel clock → 640 pixels per line = 64 µs.
Board clock can be 10/20/30/40 MHz; CLK_MHZ generic divides it down.
V_TOTAL = 625 lines × 64 µs = 40 ms → 25 Hz frame rate.

H Timing (one line)

H_FRONT=16 → H_SYNC_W=47 → H_BACK=57 → H_ACTIVE=520
Sync tip: h_cnt 16–62 (4.7 µs LOW on csync).
Active pixels: h_cnt 120–639 (52 µs).

V-Sync Pulse Sequence

15 half-lines around each field boundary:
5× Pre-equalising: 2.3 µs LOW per half-line
5× Broad sync: 27.3 µs LOW (fills half-line)
5× Post-equalising: 2.3 µs LOW per half-line

FSS Output

Field Synchronising Signal — 50 Hz square wave.
F1 FSS: v_cnt 3–7 (lines 4–8 scope).
F2 FSS: v_cnt=315 h≥320 → v_cnt=320 h<320
(starts scope line 314 last half, ends line 319 first half).

Active Video Windows

F1 active: v_cnt 25–311, h_cnt 120–639
F2 active: v_cnt 337–623, h_cnt 120–639
288 lines per field × 520 pixels = 149,760 px/field.
BRAM stores 2 fields → 299,520 bits.

DAC Levels (4-bit R-2R)

LEVEL_SYNC = 0x0 → 0 V (sync tip)
LEVEL_BLANK = 0x4 → back porch / blanking
LEVEL_WHITE = 0xF → peak white (video)

BRAM Frame Buffer

1-bit per pixel, double-buffered (ping-pong).
Write side: CPU/DMA fills next frame.
Read side: pixel engine reads current frame.
Swap on v_cnt=V_FRAME_S → tear-free output.
